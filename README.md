# 🤖 FB Messenger Userbot v2.0.0

بوت Facebook Messenger مبني على `fca-unofficial` مع دعم كامل لرسائل **المحادثات الفردية والجماعية**، لوحة تحكم مباشرة، نظام اقتصاد عملات، قاعدة بيانات SQLite، وأكواد مجدولة (cron).

---

## ⚙️ الإعداد

### 1. إعداد الكوكيز (appstate.json)

**الطريقة الموصى بها:**
1. افتح [messenger.com](https://www.messenger.com) في Chrome
2. اضغط على **أي محادثة** لفتحها (هذا يضيف كوكي `m_sess` الضروري)
3. ثبّت إضافة [Cookie-Editor](https://cookie-editor.com/)
4. اضغط Export → JSON → انسخ الكل
5. الصق المحتوى في ملف `appstate.json` أو عبر لوحة التحكم

### 2. إعداد config.json

انسخ `config.example.json` إلى `config.json` وعدّله:

```json
{
  "botName": "My Bot",
  "prefix": "/",
  "ownerID": "YOUR_FACEBOOK_UID",
  "adminIDs": ["ADMIN_UID"],
  "dashboardPort": 3000,
  "timezone": "Africa/Algiers"
}
```

> **ملاحظة:** `ownerID` هو الـ `c_user` الموجود في الكوكيز.

### 3. تثبيت الحزم

```bash
pnpm --filter @workspace/fb-messenger-bot install
```

### 4. التشغيل

```bash
pnpm --filter @workspace/fb-messenger-bot run dev
```

لوحة التحكم ستكون على: `http://localhost:3000`

## ➕ إضافة أمر جديد

أنشئ ملف `src/commands/yourcommand.js`:

```js
module.exports = {
  config: {
    name: "hello",
    aliases: ["hi"],
    description: "Say hello",
    usage: "hello",
    adminOnly: false,
  },
  async run({ api, event, args, threadID, senderID, isGroup }) {
    api.sendMessage(`Hello! 👋 isGroup: ${isGroup}`, threadID);
  },
};
```

## ⚠️ تنبيه

- `appstate.json` و `config.json` و `data/` مستثناة من Git لحماية بياناتك.
- لا تشارك ملف الكوكيز مع أحد.

### قفل الاسم والإرسال التلقائي

الأمثلة تستخدم البادئة `/`؛ استبدلها ببادئة البوت المضبوطة لديك إذا غيّرتها.

- `/اسم اسم المجموعة`: يغيّر اسم المجموعة ويقفله. عند رصد تغيير الاسم تُجدول إعادته بعد وقت عشوائي بين 5 و10 ثوانٍ. `/اسم ايقاف` يلغي القفل وأي إعادة معلّقة.
- `/انسخ` يبدأ الإرسال، و`/توقف` يوقفه. يمكن أيضاً استخدام `نسخ` بدلاً من `انسخ`.
- `/انسخ وقت 5m` يضبط انتظار النسخ على 5 دقائق، و`/انسخ وقت 40s` يضبطه على 40 ثانية. يمكن أيضاً كتابة رقم دون لاحقة مثل `/انسخ وقت 30` للثواني. الإعداد خاص بهذه المحادثة، والقيم المقبولة من 1 إلى 86400 ثانية (1440 دقيقة). `/انسخ وقت` يعرض الإعداد، و`/انسخ وقت افتراضي` يعيده إلى الانتظار العشوائي الأصلي (20–35 ثانية). يسري التعديل عند جدولة الرسالة التالية ولا يغيّر مؤقتاً بدأ بالفعل.

الانتظار يسبق محاكاة الكتابة وإرسال الرسالة، لذلك قد يكون الفاصل الفعلي أطول. إعدادات القفل والوقت تحفظ في الذاكرة فقط وتُفقد عند إعادة تشغيل البوت. يعتمد القفل على وصول أحداث Messenger؛ عند استخدام وضع الاستطلاع البديل يُكتشف التغيير في دورة الاستطلاع للمحادثات الموجودة في قائمته، ثم يبدأ انتظار 5–10 ثوانٍ.
